The Tarot Revue

Every value below is read off tokens.css at load and printed as the browser resolved it. Nothing on this sheet is typed twice, so it cannot quietly disagree with the token file. If a swatch looks wrong, the token is wrong.

Grounds

Spec §1

Surfaces, not accents. A ground should hold the majority of a composition. Olive is the one to watch — it goes brown the moment anything warm sits next to it.

Metallic

Spec §1

Structural, not decorative. Old brass and dull gilt. Brass is for hardware and rules and is nearly invisible as text on cream — the contrast table below says how invisible.

Interruption

One per composition

A glove, a nail, a title, one block of type. Two of these in one artifact means one of them is wrong. This sheet has picked pink, so orange appears here as a swatch and nowhere else.

Neutrals

Spec §1

Warm near-black on paper. No pure black, no pure white, no neutral gray — ink-thin is ink diluted with cream rather than a gray borrowed from somewhere else.

Semantic aliases

Reference these, not the palette

Widgets should point at the right-hand column so a palette change propagates instead of being chased through six files.

Contrast

Computed, not estimated

WCAG 2.1 ratios calculated in the page from the resolved token values. Body copy wants 4.5, large text and rules want 3. The failures are not all bugs — brass on cream is hardware, not type — but nothing should fail by accident.

Type scale

Three roles, never a fourth

Tarot Regular has already had its entrance in the masthead, so the cover row here is its second and final appearance on this sheet. Fraunces carries editorial, IBM Plex Sans carries everything informational — which is why this paragraph, the tables and every label are set in it.

Space

Base unit 8px

Five steps. Anything between them is a mistake.

Structure and material

Spec §3–§5

Radius is 0 everywhere. Shadows are a light on a real object, not a UI effect. Misregistration is ±2–4px, on decorative layers only, never on text.
